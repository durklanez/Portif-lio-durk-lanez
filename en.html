Projeto em Destaque

Inteligência App

Inteligência App é um projeto de software desenvolvido com Python e Flask, criado para integrar recursos de Inteligência Artificial em uma aplicação web através da Groq API.

O projeto utiliza Firebase e Firestore para autenticação de usuários e gerenciamento de dados e sessões. O backend é responsável pela comunicação entre a aplicação e os diferentes serviços através de APIs.

A aplicação está hospedada na nuvem utilizando Render, reunindo na prática conhecimentos de desenvolvimento backend, APIs REST, bancos de dados, Inteligência Artificial, autenticação e deploy em nuvem.
