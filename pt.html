Projeto em Destaque

Inteligência App

O Inteligência App é um projeto de software desenvolvido com Python e Flask, criado para integrar recursos de Inteligência Artificial em uma aplicação web através da Groq API.

O projeto utiliza Firebase e Firestore para autenticação de usuários, gerenciamento de dados e sessões. O backend é responsável pela comunicação entre a aplicação e diferentes serviços através de APIs.

A aplicação está hospedada na nuvem utilizando Render, reunindo conhecimentos práticos de desenvolvimento backend, APIs REST, bancos de dados, Inteligência Artificial, autenticação e implantação em nuvem.
